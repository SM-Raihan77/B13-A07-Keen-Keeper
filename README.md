



                               About the Project

KeenKeeper is a simple web app that helps you stay connected with your friends.
You can track when you last talked to someone and quickly log interactions like calls, texts, or video chats.



                               Technologies Used
React.js
React Router
Tailwind CSS
Context API
React Toastify
Recharts



                                Key Features

 View all your friends in a clean card layout
 Quickly add interactions (Call, Text, Video)
 See all your activity in a timeline.
